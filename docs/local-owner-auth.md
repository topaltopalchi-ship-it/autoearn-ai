# مالک و امنیت محلی

AutoEarn AI برای استفاده یک‌نفره طراحی شده است.

## راه‌اندازی

پیش از اجرای برنامه دو متغیر را تنظیم کنید:

- `AUTOEARN_MASTER_PASSWORD`: رمز ورود مالک.
- `AUTOEARN_AUTH_SECRET`: یک مقدار تصادفی و طولانی برای امضای نشست‌های محلی.

نمونه در `.env.example` قرار دارد. فایل واقعی `.env` را به Git اضافه نکنید.

APIهای برنامه فقط از اتصال loopback پذیرفته می‌شوند و APIهای محافظت‌شده علاوه بر آن به نشست معتبر مالک نیاز دارند.

## نکات امنیتی

- رمز مالک در پایگاه داده ذخیره نمی‌شود.
- نشست با کوکی HttpOnly و امضای HMAC نگهداری می‌شود و پس از ۱۲ ساعت منقضی می‌شود.
- اگر `AUTOEARN_MASTER_PASSWORD` یا `AUTOEARN_AUTH_SECRET` تنظیم نشده باشد، APIهای عملیاتی با خطای 503 متوقف می‌شوند.
- کلیدهای API و اطلاعات حساب‌ها را تا تکمیل بازبینی امنیتی و پشتیبان‌گیری امن وارد نکنید.
- برنامه را روی اینترنت، LAN یا tunnel عمومی قرار ندهید.

## محدودیت

این احراز هویت برای مالک محلی است و جایگزین مدیریت هویت سازمانی یا سرویس عمومی چندکاربره نیست.
